# Getting help

| You need… | Go to |
| --- | --- |
| To report a bug in a repository you can access | Open an issue with the **Bug report** template |
| To suggest a feature or improvement | Open an issue with the **Feature request** template |
| To report a security vulnerability | **Never in an issue** — follow [SECURITY.md](SECURITY.md) |
| Help with a product we built or run for you | Your usual Th1nkDev contact, or [contact@th1nkdev.com](mailto:contact@th1nkdev.com) |
| To start a new project or get a quote | [th1nkdev.com/start-a-project](https://th1nkdev.com/start-a-project) |
| To talk it through first | [Book a call](https://th1nkdev.com/book) |
| Training for you or your team | [Th1nkDev Academy](https://th1nkdev.com/academy) |
| To join the team | [Careers](https://th1nkdev.com/careers) |

Clients under a maintenance agreement are supported through the channel and response times defined in that agreement.

---

🇫🇷 **Besoin d'aide ?** Un bug ou une idée : ouvrez un ticket avec le modèle adapté. Une faille de sécurité : jamais en ticket, voir [SECURITY.md](SECURITY.md). Un projet, un devis ou une formation : [th1nkdev.com](https://th1nkdev.com) ou [contact@th1nkdev.com](mailto:contact@th1nkdev.com). Les clients sous contrat de maintenance passent par le canal prévu au contrat.
